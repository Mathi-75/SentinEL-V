# Data Format Description: SentinEL-V Telemetry Logs

The CSV datasets provided in this repository are auto-generated by the SentinEL-V Python Command Center. The data represents live, 2Hz serial telemetry processed entirely at the edge by the VSDSquadron Ultra RISC-V microcontroller. 

Because all signal conditioning (Kalman Filtering) and anomaly detection (Decision Tree) occurs directly on the silicon edge, the logged data represents the *post-processed* predictive system state.

## Dataset Files Included

* **`Raw_Data_Sample.csv`**: Baseline logs captured during normal, stable room-temperature operation.
* **`Fault_Test_Data.csv`**: Logs captured during physical validation testing (simulating a thermal runaway event using localized heat and VOC gas).
* **`Processed_Data_Output.csv`**: The complete Edge AI output log, showcasing the Risk Score and Time-to-Failure (TTF) predictions leading up to a system SCRAM event.

## CSV Data Dictionary

| Column Header | Data Type | Description |
| :--- | :--- | :--- |
| `timestamp_s` | Float | Elapsed time in seconds since the VSDSquadron Ultra booted. |
| `temp_c` | Float | Battery cell temperature (°C) after passing through the embedded 1D Digital Kalman Filter. |
| `ror` | Float | Rate of Rise ($dT/dt$). The thermal velocity representing the °C increase per sample. |
| `gas_raw` | Integer | Filtered ADC value from the MQ-135 VOC sensor (used by the AI for dynamic baseline delta calculation). |
| `class_id` | Integer | Raw deterministic output from the Edge AI Decision Tree (`0`=SAFE, `1`=PRE-WARN, `2`=WARNING, `3`=CRITICAL). |
| `state` | String | Human-readable system state tied directly to the `class_id`. |
| `risk_score` | Integer | Continuous 0-100 metric aggregating thermal velocity, absolute heat, and VOC displacement. |
| `ttf_sec` | Float | Predictive Time-To-Failure (seconds). Estimates the time remaining until the cell hits 60°C. Reads `-1` if the temperature is stable. |
| `soh_pct` | Integer | State of Health (0-100%). Reflects simulated lifetime thermal stress degradation. |
